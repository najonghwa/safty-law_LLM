# 안전법규 통합 DB — 웹 배포판

국가법령정보센터(law.go.kr) 현행 법령을 조(條) 단위로 수집해 SQLite에 넣고,
LLM이 **검색된 조문만** 근거로 답하게 만든 검색 서비스. Vercel 서버리스로 배포한다.

법령은 수시로 개정되므로, 답을 외우는 대신 **DB를 갱신해서 다시 찾는 쪽**이 낫다는 생각으로 만들었다.

```
공개 사이트 → /api/index.py (단일 서버리스 함수) → data/laws.db (읽기 전용)
                     └→ OpenAI API (gpt-4o-mini)
```

## 할루시네이션을 막는 3중 게이트

법 조항은 틀리면 곧바로 실무 리스크라, 모델을 믿는 대신 코드로 막았다.

1. **검색 게이트** — 근거 조문을 못 찾으면 조항을 인용하는 답변을 아예 만들지 않는다.
   대신 "DB 미확인 · AI 일반 지식"이라고 표시하고 일반 답변을 준다(조항 번호 언급 금지).
2. **폐쇄형 생성** — LLM에는 검색으로 확정된 조문만 넣고, 그 밖의 지식 사용을 금지한다.
3. **인용 검증** — 답변의 `[n]`이 실제로 제공한 조문 번호인지 코드로 확인하고, 벗어난 인용은
   지운다. 남는 인용이 하나도 없으면 그 답변은 버린다.

물질 질문(예: "디메틸아민은 유해화학물질인가?")은 별표를 대조한 **확정 등재 내역**을
근거 [1]로 고정해 넣는다. 별표가 커서 본문 검색만으로는 해당 행을 놓치기 때문이다.

## 검색이 현장 용어를 알아듣는 방법

"불산", "폐액", "MSDS" 같은 현장 표기는 법령 원문에 없다. 동의어 사전으로 다 담을 수 없어
(화학물질 이명만 수천 개) **LLM에게 검색어를 만들게 한다**(`plan_query`).
그 결과와 규칙 기반 검색 결과를 RRF(순위 융합)로 합쳐, 여러 검색어에 공통으로 잡힌 조문을
위로 올린다 — LLM이 검색어를 한 번 빗나가도 정답 조문이 밀려나지 않는다.

## 품질 측정

`eval.py` — 실제 실무 질문 35건 + 거부 3건으로 회귀를 잡는다. 코드를 고칠 때마다 돌린다.

```
검색 정확도 35/35 (100%)   기대 법령·조문이 LLM에 전달된 8건 안에 들어갔는가
답변 근거정확 35/35 (100%)  실제로 그 근거를 인용해 답했는가
거부 정확도  3/3            법규와 무관한 질문을 조문으로 억지로 엮지 않았는가
```

## 로컬 실행

```bash
export OPENAI_API_KEY=sk-...      # PowerShell: $env:OPENAI_API_KEY="sk-..."
python dev_server.py              # http://localhost:8788
```

`dev_server.py`는 Vercel과 같은 라우팅(정적 `public/` + `/api/*` → `api/index.py`)을 흉내 낸다.
표준 라이브러리만 쓰므로 설치할 패키지가 없다.

## Vercel 배포

1. Vercel에서 이 저장소를 Import (Framework Preset: **Other**)
2. Settings → Environment Variables 에 `OPENAI_API_KEY` 추가
3. Deploy

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | (필수) | 없으면 검색·조문 열람만 되고 AI 질의는 안내 문구를 낸다 |
| `OPENAI_MODEL` | `gpt-4o-mini` | |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | OpenAI 호환 API면 사내 엔드포인트로 교체 가능 |

## 엔드포인트

`vercel.json`의 rewrite가 `/api/*`를 전부 `api/index.py` 하나로 보낸다.
엔드포인트를 파일별로 쪼개면 함수마다 37MB DB가 복사되기 때문이다.

| | |
|---|---|
| `GET /api/stats` | DB 현황 |
| `GET /api/laws` | 법령 목록(그룹별) |
| `GET /api/law?law_id=` | 한 법령의 조문 목차 |
| `GET /api/article?id=` | 조문 원문 |
| `GET /api/search?q=&tier=` | 키워드 검색 |
| `GET /api/substance?q=` | 물질(CAS/이름) 규제 목록 대조 |
| `POST /api/ask` | AI 질의 — `{"q": "..."}` |
| `POST /api/review` | 제품 검토 — `{"topic": "...", "product": {...}}` |

## 파일

```
api/index.py      모든 /api/* 요청을 받는 단일 함수 (경로로 분기)
api/_lib.py       DB 접근 · 검색 · 물질 대조 (밑줄 시작이라 함수로 배포되지 않는다)
api/_rag.py       질의 파이프라인 · 프롬프트 · 3중 게이트
data/laws.db      법령 DB (읽기 전용, 2026-07-21 수집)
data/synonyms.json 현장 용어 → 법령 용어
public/index.html 화면 전체
eval.py           품질 평가셋
dev_server.py     로컬 확인용
```
